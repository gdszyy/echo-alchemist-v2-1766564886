# 模块专用文档：Lowpoly 离散化与风格化模块 (像素美学版)

## 1. 模块概述
本模块将 SDF 场转化为 Lowpoly 网格。针对 120x120 像素空间，网格生成的策略是“**极简几何，强力着色**”，确保生物在小尺寸下依然具有极强的结构感。

## 2. 核心技术要素

### 2.1 极低面数对偶轮廓 (Ultra-Lowpoly DC)
*   **面数预算控制**：强制将总面数控制在 300-500 三角形之间。在 120 像素分辨率下，过多的面数会导致视觉混乱。
*   **QEF 特征吸附**：利用 QEF 算法将顶点精确吸附到主要的解剖棱线上，确保生物的“剪影”在 120 像素下清晰可辨。

### 2.2 像素级风格化处理
*   **平直着色强化 (Aggressive Flat Shading)**：通过顶点分裂，确保每个面片都有完全独立的法线。在低分辨率下，这能产生类似像素画的明暗块面。
*   **边缘加粗模拟**：在网格化阶段，通过调整 QEM 权重，在生物轮廓处保留更多几何细节，模拟“描边”效果。

### 2.3 顶点色与调色板
*   **高对比度着色**：使用有限的调色板（如 16 色），将材质 ID 映射到高对比度颜色上，提升在 120 像素空间内的视觉冲击力。

## 3. 输入与输出
*   **输入**：低分辨率 SDF、面数预算（<500）、高对比度调色板。
*   **输出**：极简 Lowpoly 静态网格。
