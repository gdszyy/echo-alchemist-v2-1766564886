# 模块专用文档：隐式表面融合模块 (低分辨率优化版)

## 1. 模块概述
本模块将骨骼与肌肉融合为 SDF 场。针对 120x120 像素的显示环境，SDF 的计算重点在于**轮廓的抗锯齿预处理**与**低分辨率下的特征保持**。

## 2. 核心技术要素

### 2.1 像素感知 SDF 采样
*   **自适应网格分辨率**：将 SDF 的采样分辨率与 120x120 像素空间对齐，避免生成过细、在像素化后消失的几何结构。
*   **窄带（Narrow Band）优化**：仅在生物表面的 120 像素范围内进行高精度采样，提升生成效率。

### 2.2 风格化平滑因子
*   **硬朗边缘控制**：减小 $k$ 值（平滑因子），使肌肉与骨骼的交界处更加硬朗。在低分辨率下，这种硬朗的过渡能产生更好的视觉辨识度。
*   **皮下脂肪简化**：减少筋膜模拟的复杂度，优先保证生物整体轮廓的清晰。

### 2.3 视角驱动的细节
*   **正面细节增强**：在面向屏幕的一侧叠加更高频的分形噪声，产生皮肤质感；背部则进行简化处理以节省计算资源。

## 3. 输入与输出
*   **输入**：视角优化肌肉场、120 像素分辨率参数、硬朗度系数。
*   **输出**：适合低分辨率显示的 SDF 数据。
