# 模块专用文档：生物力学与物理验证模块 (正面视角版)

## 1. 模块概述
本模块针对“面向屏幕”和“向前移动”的特定需求，验证生物的物理合理性。在 120x120 的有限空间内，物理验证的重点从全向平衡转向**纵向推进稳定性**。

## 2. 核心技术要素

### 2.1 纵向平衡与推进分析
*   **向前移动惯性补偿**：计算生物在向前移动时的质心偏移。由于生物不进行转向，只需验证在 Y 轴（前进方向）上的动态平衡。
*   **支撑多边形简化**：在正面视角下，简化足部与地面的接触判定，确保在 120 像素宽度内有足够的支撑基底。

### 2.2 像素级异速生长
*   **视觉粗细修正**：在低分辨率下，过细的骨骼会产生像素断裂。模块引入“最小像素宽度”约束，强制骨骼直径在 120 像素空间内不低于特定阈值（如 3-5 像素）。
*   **载荷简化计算**：由于动画精简，仅计算待机和移动状态下的静态/动态载荷，忽略复杂的攀爬或跳跃应力。

### 2.3 空间排斥优化
*   **正面防穿插**：重点检测在正面视角下可能重叠的肢体，通过排斥场确保各肢体在 X-Y 平面上有清晰的视觉间隔。

## 3. 输入与输出
*   **输入**：视角优化骨骼、向前移动速度预设、最小像素宽度限制。
*   **输出**：具备视觉饱满度且物理稳定的骨架参数。
