# 模块专用文档：拓扑生成模块 (空间约束版)

## 1. 模块概述
本模块负责在严格的 120x120 像素空间约束下生成生物骨骼拓扑。由于生物面向屏幕且仅向前移动，生成逻辑从全向生长转向**视角优先（View-First）**的生长策略。

## 2. 核心技术要素

### 2.1 空间边界框约束 (AABB Constraint)
*   **硬性裁剪**：L-系统的生长规则中嵌入坐标检查，任何超出 $[-60, 60]$（以中心为原点）范围的骨骼段将被自动修剪或重定向。
*   **紧凑型布局**：优先采用向中心集中的拓扑结构，确保生物在 120 像素宽度内视觉效果最饱满。

### 2.2 正面视角优化 (Frontal View Optimization)
*   **深度层级管理**：由于面向屏幕，骨骼在 Z 轴（深度）上的分布被压缩，重点强化 X-Y 平面的拓扑复杂度。
*   **对称性强化**：严格执行左右对称，因为正面视角下任何不对称都会被像素化显示放大。

### 2.3 动画预设拓扑
*   **移动支撑轴**：针对“向前移动”，自动生成强化的纵向支撑骨骼。
*   **受击反馈节点**：在躯干中心预留高频振动节点，用于承载受击动画的位移反馈。

## 3. 输入与输出
*   **输入**：120x120 空间参数、正面视角权重、L-系统规则。
*   **输出**：空间受限且视角优化的骨骼拓扑图。
