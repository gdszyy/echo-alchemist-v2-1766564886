# 激光折射机制设计方案

## 1. 背景与目标
当前《Echo Alchemist V2》中，激光属性（Laser）和反弹属性（Bounce）的联动表现为：激光撞击墙壁或带盾敌人时发生镜面反射。这种机制在实际游戏中显得较为“鸡肋”，因为激光通常是瞬间穿透一条直线，很难像实体弹珠那样通过多次物理弹射造成大范围伤害。

为了提升激光流派的爽快感和实战价值，本次优化的目标是将激光的“反弹”改造为“折射（Refraction）”系统：
- **核心概念**：当激光击中敌人后，有概率触发折射，自动寻找范围内的随机敌人，并向其发射剩余长度的折射光线。
- **资源消耗**：每次折射消耗 1 层 `bounce`（反弹）属性。
- **链式反应**：折射出的光线可以继续触发折射，直到剩余长度耗尽或反弹层数归零。

## 2. 机制设计细节

### 2.1 触发条件
- **触发时机**：在激光射线处理穿透伤害（`combat_laser_processPenetration`）时，对路径上命中的每一个普通敌人进行判定。
- **触发概率**：每次命中敌人时，独立计算触发概率。基础概率可设为 `30%`，每层 `bounce` 属性额外增加 `5%` 的概率，最高上限 `80%`。
  - *公式*：`P(折射) = min(0.8, 0.3 + bounce * 0.05)`
- **消耗**：触发成功且有剩余 `bounce` 层数时，消耗 1 层 `bounce`。

### 2.2 折射目标选择
- **范围限制**：以当前被击中的敌人为中心，设定一个折射搜寻半径（例如 `150px`）。
- **目标筛选**：
  - 必须是存活的敌人（`active === true`）。
  - 不能是当前被击中的敌人本身。
  - 不能是已经被这条激光（包括其祖先射线）击中过的敌人（防止在两个敌人之间无限死循环折射）。
- **随机选择**：从符合条件的敌人中随机挑选一个作为折射目标。

### 2.3 折射射线生成
- **起点**：当前被击中敌人的中心位置。
- **方向**：指向选中的折射目标中心。
- **剩余长度**：继承当前激光射线撞击到该敌人时的剩余长度（即 `remainLen - segmentLen`，需要将剩余长度传递给穿透处理函数）。
- **伤害衰减**：折射出的射线造成的伤害，应基于当前命中敌人的衰减后伤害，并可额外附加一个折射衰减系数（例如 `0.8`）。

### 2.4 递归与循环控制
为了避免深度递归导致栈溢出或性能问题，采用**队列（Queue）**的方式来处理折射。
- 维护一个 `laserQueue`，初始放入主射线任务。
- 每次从队列中取出一个射线任务执行（寻找反射面、处理穿透）。
- 在处理穿透时，如果触发了折射，则将新的射线任务（起点、方向、剩余长度、剩余反弹次数、已命中敌人集合、当前伤害）加入 `laserQueue`。
- 限制最大处理队列长度或单次发射的最大折射总次数（例如最多 50 次折射），以防极端情况。

## 3. 代码修改规划

### 3.1 修改 `combat_system.js`
- **函数 `combat_laser_fire`**：
  - 引入队列机制重构射线生成逻辑。
  - 维护 `bounces`（剩余反弹次数）作为全局或队列任务的属性。
  - 记录已命中的敌人集合 `hitEnemiesSet`，避免重复击中。
  - 在调用 `combat_laser_processPenetration` 时，传递当前射线的剩余长度、剩余反弹次数、已命中集合、当前伤害等参数。
  - 接收 `combat_laser_processPenetration` 返回的折射任务列表，并加入队列。

### 3.2 修改 `src/combat/collision.js`
- **函数 `combat_laser_processPenetration`**：
  - 接收额外的参数：`remainLen`（当前射线剩余长度）、`bounces`（剩余反弹次数）、`hitEnemiesSet`（已命中集合）、`currentDamage`（当前射线基础伤害）。
  - 在遍历命中敌人并计算伤害后，进行折射判定：
    - 如果 `bounces > 0` 且 `Math.random() < 触发概率`：
      - 寻找范围内的合法目标。
      - 如果找到，生成折射任务对象（包含新起点、新方向、新剩余长度、新伤害等）。
      - 扣除 `bounces`，将该敌人加入 `hitEnemiesSet`。
  - 返回所有生成的折射任务列表，供主循环加入队列。

## 4. 视觉与表现
- 折射出的射线在视觉上应该比主射线稍微细一点，或者颜色略有差异（例如增加透明度）。
- 每次折射发生时，在折射点生成特殊的火花粒子特效（如黄绿色火花，代表 Bounce 属性的触发）。
- 播放清脆的折射音效。
