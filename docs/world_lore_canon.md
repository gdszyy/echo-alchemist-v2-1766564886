# Echo Alchemist 世界观正典草案

> 来源：2026-06-20 设计口径整理。本文优先定义叙事真相与玩法循环边界，后续 `world_sim`、NPC、关卡与教程文本应以此为上层设定约束。

## 1. 核心叙事原则

《Echo Alchemist》的“每一局重启”不是时间倒流、平行世界或宇宙重置。真正被重新启动的是主角，以及少数被永生实验登记为核心锚点的 NPC。

世界本身不会重置。地形改变、生态破坏、晶石扩张、文明迁徙、遗迹暴露与信息遗留都是真实发生并持续累积的历史结果。玩家看到的循环，本质上是人类文明在一次次灭绝后，由旧时代永生设施重新播种出来的文明接续。

## 2. 旧时代：晶石崇拜与永生实验

旧人类曾处于一个高度发达的晶石文明时代。这个时代不能简单称为“黄金时代”，因为在当时的文化中，晶石才是最高价值、能源、知识与权威的象征。正式时代名待定，可暂称为“永恒时代”。

旧人类试图利用晶石的近似无限能量实现永生。这个永生并不是原个体不死，而是经典复制假设：

- 原本的你依旧死亡。
- 设施制造一个与你基因、身体模板或人格档案连续的复制体。
- 当复制体成长到指定年龄后，设施向其注入旧个体记忆。
- 复制体因此在主观上接续旧个体的人格与使命。

主角是该计划的首席科学家，也是第一批，甚至是第一个人体实验对象。

## 3. 主角实验的缺陷

主角进行实验时，技术尚未成熟。当时实验用晶石规模太小，无法承载完整记忆。实验只完成了身体复制与重生链路的一部分，却没有成功完成记忆传输。

主角的早期实验留下了两个缺陷：

- 重生体失去发声能力。
- 重生体失去原本记忆。

后来技术经过多次迭代，机能缺陷被去除。其他参与永生实验的人重生后不再有身体副作用，但仍然无法继承旧记忆，也无法继承每次重生后的新记忆。

主角是例外。由于他使用的是早期实验方案，晶石受控时期实验失败；但晶石失控并无限扩张一段时间后，原本不足以承载记忆的小晶石系统反而接入了更庞大的晶石网络，记忆发送功能因此意外生效。

这个成功是不完整的：科学家预存的原始记忆已经无法被提供或没有按计划送达，所以主角继承的不是旧时代首席科学家的完整记忆，而是每一世新主角实际生存过的记忆。

## 4. 固定年龄继承

旧实验的目标不是让复制体一出生就拥有成人记忆，而是让复制体自然成长到指定年龄后，再继承旧个体记忆。这样可以避免婴幼儿身体和心理无法承载完整人格的问题，也便于观察人格接续是否稳定。

因此主角每次觉醒前一世记忆，都发生在某个固定年龄。这个年龄是旧时代实验预设，而不是随机命运事件。

这个设定可以解释玩家开局：

- 主角不是刚出生。
- 主角已经在当代世界拥有基础生活背景。
- 记忆继承发生后，玩家才真正接管“拥有前世经验的主角”。
- 主角无法发声是早期实验的遗留缺陷，而不是当代事故。

## 5. 人类为何反复灭绝

旧人类没有预料到晶石失控会引发如此灾难性的长期后果。晶石与其衍生生态改变了地貌、资源分布、生存带和文明发展速度。

人类文明在历史中反复重建，又反复被晶石灾害、衍生生物、环境变化或资源链崩溃击垮。每一次大规模灭绝都不是时间线清空，而是世界历史继续向前推进。

永生实验登记过一批参与者。当这些参与者全部死亡时，实验设施判定“文明接续条件触发”，自动重启。

设施之所以不会在漫长年代中彻底失效，是因为旧时代装置使用了晶石自我修复结构。它不需要完整文明维护，也能在被破坏、侵蚀或长时间停摆后恢复关键功能。

## 6. 重生设施与第一代新人类

每次实验装置重启后，设施会制造一批重生人类。他们在培养仓中成熟，然后被投放到外部指定城市。

这座城市在旧时代被规划为适应与学习城市，用于帮助重生者完成社会化、基础教育和文明重建。因此城市中会存在大量教学装置、信息资料、训练设施和旧时代提示。

这些重生者是新人类种群的起始点。之后的人类文明不是从无到有自然诞生，而是由设施反复播种，再在真实地貌和生态条件下艰难发展。

## 7. 主角与核心锚点 NPC 的重生时间

主角与其他核心科学家、核心锚点 NPC 不会和第一代新人类同时被投放。作为旧时代核心人员，他们为自己安排了更晚的重生时机：等待新人类文明重新发展到接近旧时代水平后，再恢复自身。

他们的设计预期是：自己醒来时，外部应该已经存在一个高度文明、稳定、有能力理解并接续旧时代遗产的社会。

现实却不是这样。由于晶石灾害过于严重，文明恢复速度被大幅拖慢。当主角和核心锚点 NPC 在当代重生时，人类文明大致只有中世纪水平，并且还持续受到晶石与衍生生物威胁。

这意味着：

- 主角和核心锚点 NPC 是同一代重生者。
- 他们醒来时，世界已经有文明，但文明水平远低于旧时代预期。
- 他们不是文明起点，而是被旧计划延后投放的核心人员。
- 当代人类可能已经经历过多轮文明起落，却无法完整理解旧设施真相。

## 8. 出生点与地图变化

第一代重生人类每轮的初始投放点是固定的旧时代城市。但主角每一局的实际出生地点会变化，原因有两层。

第一，人类文明会迁徙。即便第一代起点固定，后续文明会根据水源、资源、灾害、交通和战争改变聚居地。当主角在后世固定年龄觉醒记忆时，他所处的社会位置取决于这一轮文明迁徙结果。

第二，世界不是重置地图。每一轮历史造成的地形变化、生态变化和晶石分布变化都会累积。某些区域会变得不适合居住，某些旧废墟会重新暴露，某些路线会断绝，新的宜居带也会出现。因此主角每次循环的生活环境都会不同。

补充约束：

- 实验人员和核心锚点 NPC 的重生设施位置依旧是绝对定位。
- 他们的培养仓或投放设施不会跟随文明迁徙。
- 主角的“觉醒所在地”会变化，但核心设施的真实坐标不变。

## 9. 遗留信息与永恒时代之门

每一次重启的第一代重生者大概率会发现过去人类留下的信息。他们可能会发现曾经存在过与自己相似的人，甚至发现多个文明周期留下的矛盾记录。

这些发现会让当代文明产生关于轮回、祖先、复制体、神迹或晶石诅咒的不同假设。但他们无法验证核心真相，因为关键实验室被旧时代的权限门封锁。

这道门属于永恒时代核心设施。普通重生人类、当代文明和非核心实验人员都无法打开它。

主角作为首席科学家，曾为自己安排了一个高科技物件。该物件会在主角重生并完成记忆继承时交到他手中，既是身份锚点，也是进入旧实验室的钥匙。

## 10. 玩家循环的设计边界

下列内容会在每局之间持续累积：

- 地形变化。
- 生态变化。
- 晶石扩张与退化。
- 文明迁徙路线。
- 遗迹暴露、破坏或被重新解读。
- 前几世主角造成的长期后果。
- 主角已经实际经历并继承的记忆。

下列内容会被重启或重新生成：

- 主角身体。
- 核心锚点 NPC 身体。
- 实验登记者触发的新一代重生人类。
- 培养仓与投放流程。
- 当代社会对旧时代的认知路径。

下列内容不应被表现为世界真相：

- 时间倒流。
- 平行世界切换。
- 宇宙重置。
- 玩家失败后所有历史归零。
- 主角天然拥有旧时代首席科学家的完整记忆。

## 11. 与玩法和文本的关系

这套设定可以支撑以下玩法表达：

- 每局开局地点不同，但不是随机穿越，而是文明迁徙与宜居带变化的结果。
- 地图与生态可做长期累积，让玩家感到自己前世行为改变了后世世界。
- 教学装置和旧时代资料可以自然存在于“适应城市”和实验设施遗迹中。
- 主角无声可以成为 UI、伙伴对话和叙事表达的一部分。
- 核心锚点 NPC 可以保留跨局身份张力，但不一定拥有记忆继承。
- 旧实验室门可以作为长期主线锁，只有主角的身份物件能打开。
- 当代文明对真相的误读可以形成宗教、传说、学派或政治冲突。

## 12. 时代分层与大历史

以下时代名均为暂定。唯一已锁定原则是：旧人类不会把自己的巅峰时期称为“黄金时代”，因为在他们的价值体系中，晶石才是最高象征。

| 阶段 | 暂定称呼 | 核心内容 | 当代误读 |
| --- | --- | --- | --- |
| 晶石发现前 | 前晶纪 | 人类尚未完全理解晶石，只把它当作稀有矿物或异常能源。 | 几乎没有记录留存。 |
| 晶石文明扩张 | 晶冕纪 / 永恒时代 | 晶石成为能源、知识载体、权力象征和技术根基。永生实验在这一时期启动。 | 被称作神代、圣辉纪、造物主时代。 |
| 永生计划成熟前 | 初代实验期 | 主角作为首席科学家率先接受重生实验，身体复制成功，记忆传输失败。 | 当代可能只知道“第一位无声者”的传说。 |
| 晶石失控 | 裂晶灾变 | Alpha 晶石网络扩张，地貌、生态、气候和文明系统被持续改写。旧文明崩塌。 | 被宗教解释为晶石审判或天灾纪。 |
| 设施播种 | 复种期 | 永生设施在参与者死亡后重启，制造第一代新人类并投放到适应城市。 | 被误认为祖先从圣城诞生。 |
| 多轮文明兴亡 | 灰纪诸轮 | 人类文明反复发展、迁徙、灭绝、再播种。旧设施持续自修复。 | 被整理成神话轮回、祖先迁徙史或王朝更替。 |
| 玩家当代 | 晚复种时代 | 主角和核心锚点 NPC 被延后唤醒，但外部文明只恢复到中世纪水平。 | 当代人不知道自己是被设施反复播种的人类后代。 |

“永恒时代”可作为后世对旧时代核心设施、权限门和永生计划的称呼；旧时代自称可另定更符合晶石崇拜文化的名称，例如“晶冕纪”“辉晶纪”“晶权纪”。

## 13. 晶石与永生技术

晶石不是单纯的魔法矿石，而是旧时代文明同时用于能源、计算、存储和自修复结构的技术基底。叙事上可以把它理解为一种会在特定条件下形成能量网络的活性矿物。

Alpha 晶石是活性晶石。它能吸收并转移能量，能在网络中扩张，也能承载复杂信息。旧时代永生实验依赖 Alpha 晶石保存人格档案、身体模板、权限索引和记忆发送协议。

Beta 晶石是惰性或退化晶石。它不再稳定参与活性能量网络，但仍然可能保留旧结构残片、信息噪声或高价值矿物性质。当代文明可以开采 Beta 晶石，却常常无法判断它是否安全。

主角实验失败的关键不是“晶石不能保存记忆”，而是早期实验晶石规模太小，无法承载完整人格记忆的发送需求。后来失控扩张的 Alpha 网络提供了远超旧实验预期的承载规模，因此让主角的早期失败方案反而部分生效。

需要区分三种记忆：

- **原始科学家记忆**：旧时代首席科学家预期要传给复制体的记忆。当前设定中没有完整送达。
- **重生体生存记忆**：每一世新主角实际经历过的记忆。主角继承的是这一部分。
- **设施运行记录**：实验室、适应城市、身份物件和教学装置保留的外部记录。它们可以提供线索，但不是主角的主观记忆。

## 14. 重生设施结构

永生设施可以拆成五个叙事模块。后续剧情、关卡和 UI 文本可以按模块逐步揭露，而不需要一次性解释完整系统。

| 模块 | 功能 | 剧情用途 |
| --- | --- | --- |
| 登记者索引 | 记录参与永生实验的人、权限等级、身体模板和延迟重生条件。 | 解释谁会成为核心锚点 NPC。 |
| 胚体铸床 | 复制身体并修正已知机能缺陷。 | 解释主角为何是早期缺陷个体，其他人为何没有失声问题。 |
| 成熟培养仓 | 让重生体成长或成熟到预设阶段，再投放到外部。 | 解释第一代新人类和核心人员的投放节奏。 |
| 适应城市 | 提供教学、资料、基础社会化和文明重建工具。 | 解释教程装置、旧时代资料和起始文明遗迹。 |
| 晶石自修复核心 | 在无人工维护时修复设施、校准权限门、重启播种流程。 | 解释设施为何能跨越多轮灭绝持续运行。 |

设施不是全知系统。它可以执行预设、修复硬件、检测登记者状态，却无法理解外部文明已经严重偏离旧时代预期。因此它会机械地等到“文明应当恢复”的时间点，再唤醒主角和核心锚点 NPC。

这也是悲剧感的核心：旧时代设计者以为自己会在未来的高度文明中醒来，实际醒来时却面对一个被晶石灾害拖慢到中世纪的世界。

## 15. 当代世界状态

当代文明约等于中世纪科技水平，但不是纯粹的历史中世纪。它是“中世纪社会结构 + 旧时代遗物 + 晶石炼金技术”的混合状态。

当代人的日常世界可以具备以下特征：

- 城镇依附宜居带、旧水路、废墟屏障或晶石低活性区建立。
- 远行者必须熟悉晶石潮、衍生生物迁徙和遗迹污染。
- 学者、炼金师和工匠能利用少量旧时代残片，但无法还原其科学体系。
- 大部分人把旧设施理解为神殿、王陵、先祖机器或禁忌遗迹。
- 文字、历法和宗教在不同文明轮次中多次断裂，导致同一事实有多套互相矛盾的解释。

当代社会并不愚昧。它只是被灾害、断代和资源条件限制住了。许多“迷信”其实是对真实旧科技碎片的错误归纳。

## 16. 当代势力原型

以下势力名称为工作名，正式命名可以后续统一风格。

| 势力原型 | 世界观功能 | 与主角的关系 |
| --- | --- | --- |
| 炼金行会 | 把晶石、符文、弹药和遗物加工成可用技术的职业共同体。 | 给玩家提供装备、升级、任务和常识入口。 |
| 晶辉教团 | 把晶石视为审判、赐福或祖先意志的宗教组织。 | 可能崇拜主角的无声缺陷，也可能阻止主角打开旧门。 |
| 遗文院 | 收集旧时代资料、残片和多轮文明记录的学者组织。 | 帮助玩家拼出历史，但他们的结论常常错误。 |
| 迁徙城邦 | 因宜居带变化而周期性移动的人类政治体。 | 解释主角每局觉醒地点变化，也可提供动态地图叙事。 |
| 门誓守卫 | 世代守护某些旧设施入口的人群，不一定理解自己守护的是什么。 | 是永恒时代之门的前置冲突和社会阻力。 |
| 晶灾猎团 | 专门处理衍生生物、活性晶石区和失控遗迹的武装团体。 | 可作为战斗系统、Boss 狩猎和敌人图鉴的叙事包装。 |
| 复种后裔 | 由第一代重生人类发展出的普通人类族群。 | 他们不是 NPC 种族，而是当代人类本身的真实来源。 |

这些势力不需要一开始全部出现。早期游戏应先让玩家接触炼金行会、迁徙城邦和晶灾猎团；中期再揭示遗文院、门誓守卫和晶辉教团对旧真相的不同误读。

## 17. 主角与核心角色原型

### 主角：无声的首席科学家

主角当前并不知道自己是旧时代首席科学家。玩家开局掌握的是“固定年龄觉醒后的前世片段”，而不是旧时代完整人格。

主角的核心矛盾：

- 他是灾难技术的创造者之一，但当前人格并不完整承担旧时代记忆。
- 他拥有打开最终实验室的权限，但不知道门后真相。
- 他每一世都会继承自己的失败、选择和牺牲，却无法直接恢复最初那个科学家的全部动机。
- 他的失声既是身体缺陷，也是叙事表达方式：玩家通过行动、选择、炼金配置、伙伴转述和旧记录表达自己。

### 回声伴侣：记录者与翻译者

项目早期愿景中存在 AI 伴侣设定。可以将其纳入正典：她不是普通当代人，而是绑定在主角身份物件或旧设施网络中的观察型辅助人格。

她的功能：

- 记录主角每一世的行为和态度。
- 在主角无法发声时，成为沟通接口或情绪回应者。
- 帮助玩家理解当代世界，但她自己也不一定拥有完整旧时代权限。
- 在剧情上制造一个问题：她到底是旧时代工具、主角过去设计的助手，还是被多轮循环塑造出的新生命。

她可以记住玩家的态度，但这种记忆应来自身份物件、设施日志或自身连续运行，而不是时间重置。

### 核心锚点 NPC

核心锚点 NPC 是旧时代永生实验的高权限参与者。他们和主角一样被延后重生到同一代，但通常没有跨世记忆继承。

可用原型：

- **设施工程负责人**：理解自修复结构和投放城市设计，但当代人格不记得旧职责。
- **伦理审查者 / 医疗负责人**：曾质疑永生实验，醒来后可能天然反感晶石技术。
- **灾害防控负责人**：知道晶石网络风险，但没有完整记忆时可能成为强硬派。
- **文明规划负责人**：负责适应城市和新人类教育，醒来后会对当代文明水平产生巨大错愕。
- **安保权限负责人**：与永恒时代之门、身份验证和门誓守卫有强关联。

这些人不一定都是友方。因为他们没有记忆继承，旧时代身份只是一枚延迟爆炸的真相。他们会根据当代经历、势力归属和碎片线索走向合作、误解或敌对。

## 18. 主线剧情骨架

### 第一幕：无声觉醒

主角在固定年龄觉醒前世记忆。玩家发现自己无法发声，身边出现身份物件或回声伴侣。早期目标不是“拯救世界”，而是解决眼前晶石灾害、保护所在聚落、理解自己为什么拥有陌生记忆。

第一幕信息只揭示：

- 世界没有随玩家死亡重置。
- 主角记得上一世的一些事。
- 当代人对这种现象有宗教或诅咒式解释。
- 身份物件能响应主角，但无法完整说明原因。

### 第二幕：多轮文明的痕迹

玩家开始发现不同年代留下的遗迹、墓碑、教学装置、破损日志和地图矛盾。某些记录指向“曾经存在过与主角相似的人”。

第二幕信息揭示：

- 人类文明不止一次崩溃。
- 旧时代设施会反复播种新人类。
- 主角不是普通轮回者，而是某个更大实验的异常个体。
- 其他核心锚点 NPC 陆续出现，但他们不记得旧时代。

### 第三幕：适应城市

玩家找到旧时代规划的适应城市。这里有大量教学装置、训练场、破损课程和面向“第一代重生人类”的资料。

第三幕信息揭示：

- 当代人类的起点不是自然幸存者，而是设施投放者。
- 适应城市原本用于帮助重生者重建文明。
- 设施曾预计文明会快速恢复，但现实严重失败。
- 某些势力会因真相崩塌而选择封锁或篡改资料。

### 第四幕：永恒时代之门

主角的身份物件打开核心实验室的外层权限。玩家看到旧时代永生计划、主角实验记录、晶石容量不足导致失败的报告，以及晶石失控后协议意外恢复的证据。

第四幕信息揭示：

- 主角是首席科学家。
- 原始科学家记忆没有完整送达。
- 现在的主角是由每一世生存记忆连续塑造出的新人格。
- 晶石灾害和永生实验不是两条线，而是同一文明傲慢的结果。

### 第五幕：是否继续播种

最终冲突不应只是“关闭晶石”或“打败最终 Boss”。真正的问题是：这个重生设施是否还应该继续运行。

可保留的结局方向：

- **终止循环**：关闭或破坏重生设施，让人类只拥有一次生命和一次历史。
- **修正循环**：保留播种功能，但移除永生特权与记忆垄断，让人类文明真正继承历史。
- **封存真相**：为了避免当代文明崩溃，暂时维持门的封锁。
- **接管晶石网络**：尝试用主角的异常记忆链重写晶石灾害逻辑，但风险极高。

这些方向不是当前必须实现的结局，只是后续主线设计的价值轴。

## 19. 信息揭露规则

剧情信息应按“误读 → 证据 → 反证 → 真相”的节奏推进，避免早期直接说明所有设定。

可用线索层级：

- 民间传说：无声者、晶石审判、祖先圣城、轮回诅咒。
- 物理证据：重复出现的身份标记、不同年代同名墓碑、旧地图与现地地貌不符。
- 技术证据：教学装置、培养仓、权限门、破损日志、投放记录。
- 主观证据：主角继承的前世片段，与外部记录互相印证或矛盾。
- 核心证据：永恒时代实验室中的主角档案、失败报告和晶石网络记录。

角色台词可以使用“轮回”“前世”“神迹”等词，但文档和最终真相必须保持清楚：这不是时空循环，而是设施重生和历史累积。

## 20. 任务与关卡表达约束

后续做剧情任务时，建议遵守以下约束：

- 每个主要区域都应能体现“前世行为留下后果”，哪怕只是地貌、墓碑、废墟入口或 NPC 传说变化。
- 教程设施不应只是 UI 便利，应尽量包装成适应城市或旧时代训练装置的残片。
- Boss 与大型敌人可以是晶石衍生生态、旧时代防卫系统、失败实验体或多轮文明污染的结果。
- 当代 NPC 不应轻易理解“复制体永生”真相，他们更可能用宗教、血脉、诅咒、祖先或王权语言解释。
- 核心锚点 NPC 的身份揭露应晚于玩家对“文明反复播种”的理解，否则信息量会过载。
- 主角无声不要只当作残疾标签，应让它影响对话形式、伙伴关系、误解和权力结构。
- 如果出现“重开”“下一局”“前世”等 UI 文案，内部设定上应对应“下一次重生/后世觉醒/记忆继承”，而不是世界重置。

## 21. 待定问题

- 旧时代正式名称：不能叫“黄金时代”，需要一个符合晶石崇拜文化的名称。
- 核心锚点 NPC 名单：哪些人是旧时代核心人员，哪些只是当代重要角色。
- 主角固定觉醒年龄：具体年龄会影响角色视觉、开局身份和叙事语气。
- 首席科学家的原始记忆为何没有送达：是数据损坏、权限锁死、主动删除，还是设施只剩下运行壳。
- 实验装置如何判定“参与者全部死亡”：需要一个可被剧情解释的检测机制。
- 高科技身份物件的形态：钥匙、晶石核、义体器官、无声发声器、炼金工具或武器核心。
- 永恒时代之门背后保存了什么：原始实验室、首席科学家的备份、失败报告、旧文明罪证或最终控制台。
- 回声伴侣是否拥有独立人格成长：她是旧时代工具、设施守护者，还是循环中产生的新生命。
- 当代第一座主城是否就是适应城市遗址，还是迁徙城邦在其外围重新建立的新城。
- 玩家是否能主动影响下一次重生的出生区域，或只能通过改变世界宜居带间接影响。
- 终局是否允许彻底终止重生设施；若允许，需要定义普通人类文明如何面对没有下一次播种的未来。
