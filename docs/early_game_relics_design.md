# 新手前期过渡遗物设计方案

## 1. 现有遗物体系盘点
目前游戏中的遗物（RELIC_DB）主要分为以下几大类：

| 类别 | 遗物示例 | 机制说明 |
|---|---|---|
| **属性解锁类** | 永恒冻土(冰)、不灭火种(火)、穿透/散射/增幅补给 | 解锁原本权重为0的特殊属性，为后期构筑奠定基础。 |
| **槽位扩展类** | 空间凿子、时光沙漏、双子魔镜 | 增加特殊槽位出现概率，提升连击与爆发上限。 |
| **形态改变类** | 维度碎片、三角阵形、菱形阵形 | 改变钉盘的行数或排列形状，影响弹珠下落轨迹与碰撞频率。 |
| **涌潮爆发类** | 增幅涌潮、穿透涌潮 | 短期内（2回合）极大提升某种弹珠的同化概率，属于爆发型收益。 |
| **特殊机制类** | 命運輪盤、倍化之术、粉红凝胶 | 提供独特机制，如轮盘翻倍、弹珠变大、增加弹性钉子等。 |

**现有体系的问题**：
现有的强力遗物（如维度碎片、空间凿子）大多属于**“乘区型”**或**“发育型”**收益。在游戏的前 10 回合，玩家基础伤害极低（Base Damage = 1），即使获得这些遗物，也很难立即将其转化为有效战斗力，容易在前期遭遇高压或 Mini-Boss 时暴毙。

## 2. 前期过渡遗物设计理念
为了改善新手体验，我们需要引入**“加值型”（Flat Bonus）**或**“前期保护型”**遗物。
这类遗物的特点是：
1. **即时生效，下限极高**：获得后立刻提供肉眼可见的战斗力提升。
2. **后期稀释，自动淘汰**：通过固定数值加成或仅在限定回合内生效，确保其在游戏后期（第 15 回合后）不会破坏数值平衡。
3. **标签明确**：全部打上 `['前期过渡', '新手友好']` 标签，并配置高权重的 `recommended: true`。

## 3. 具体设计方案 (4 款新遗物)

### 方案 A：固定数值加伤（全弹药生效）
**遗物 ID**: `early_flat_damage`
**名称**: 粗制火药管
**图标**: 🧨
**描述**: 简单粗暴的火力提升。你的所有弹珠基础伤害 +2。
**机制实现**: 在 `ui_selectRelic` 中设置 `this.flatDamageBonus = (this.flatDamageBonus || 0) + 2`，在 `combat_system.js` 的配方构建阶段将其加到 `finalRecipe.damage` 中。
**推荐 Tip**: 前期最强过渡遗物！让所有子弹伤害翻倍，轻松碾压前期敌人。

### 方案 B：限时护盾（容错率提升）
**遗物 ID**: `early_temp_shield`
**名称**: 守护者结界
**图标**: 🔰
**描述**: 获得 5 层护盾。每当敌人触底时消耗 1 层护盾抵消伤害。
**机制实现**: 在 `ui_selectRelic` 中设置 `this.playerShield = (this.playerShield || 0) + 5`，在 `input_checkDefeat` 判定越线时，优先扣除护盾而非直接 Game Over。
**推荐 Tip**: 极高的容错率！即使漏怪也能保命，适合还在熟悉操作的新手。

### 方案 C：前 N 回合无条件秒杀小怪
**遗物 ID**: `early_execute_aura`
**名称**: 威压光环
**图标**: 👁️
**描述**: 获得后接下来的 5 个回合内，所有普通敌人（非 Boss）血量上限强制减半。
**机制实现**: 在 `ui_selectRelic` 中记录获取时的回合数 `this.auraStartRound = this.round`，在 `spawn_system.js` 计算敌人血量时，若 `this.round <= this.auraStartRound + 5` 且非 Boss，血量减半。
**推荐 Tip**: 获得后立即进入 5 回合的爽快割草期，助你安稳度过前期危险期！

### 方案 D：初始经济爆发
**遗物 ID**: `early_economy_burst`
**名称**: 走私者的钱袋
**图标**: 💰
**描述**: 立即获得 500 点局内货币（Score），且前 5 回合所有分数收益翻倍。
**机制实现**: 在 `ui_selectRelic` 中直接调用 `this.spawn_addScore(500)`，并设置 `this.doubleScoreRounds = 5`，在加分逻辑中进行判定。
**推荐 Tip**: 赢在起跑线上！巨大的经济优势让你能在商店中买空所有强化。

## 4. 落地建议
建议优先实装**方案 A（粗制火药管）**和**方案 B（守护者结界）**，因为它们最直接地解决了“前期伤害低打不死怪”和“漏怪直接死”这两个新手核心痛点。我们可以将它们加入 `RELIC_DB` 并配置在首回合必出的推荐池中。
