# Echo Alchemist V2: Boss 及随从异型视觉设计与几何顶点规格书

本文档详细定义了《Echo Alchemist V2》中 8 个 Boss 及其随从的异型几何外观设计。根据任务要求，我们将打破现有的统一圆角矩形（`roundRect`）渲染框架，为 Boss 和特殊随从引入多边形（Polygon）碰撞与渲染机制。设计风格定调为 **“几何虚空 (Geometric Void)”**，强调冷峻的切面、不对称的异化感以及强烈的能量溢出视觉表现。

## 1. 渲染与碰撞框架升级说明

当前的渲染系统（`enemy.js` 中的 `draw` 方法）和碰撞系统（`collision.js`）均基于 AABB（轴对齐包围盒）和 `roundRect`。引入异型设计后，需在实体中新增 `shape` 属性和 `vertices`（顶点坐标数组，基于中心点 `[0,0]` 的相对坐标，范围在 `[-w/2, w/2]` 和 `[-h/2, h/2]` 之间）。

非正方形（多边形）边缘将导致子弹（激光/弹射）的法线（Normal）发生改变，不再仅限于垂直或水平反弹，而是根据击中边的法向量进行镜面反射，极大地增加了战斗的不可预测性和对玩家几何预判能力的考验。

## 3. 后续开发建议 (供开发 Agent 参考)

在 `entities.js` 中，为 `Enemy` 类新增 `polygon` 属性数组，并在 `draw` 方法中将 `ctx.roundRect` 替换为遍历 `polygon` 顶点的 `ctx.moveTo` 和 `ctx.lineTo`。在 `collision.js` 中，需引入多边形与圆（子弹）的 SAT（分离轴定理）碰撞检测，以计算准确的碰撞法线用于反射。噬神者的 V 型凹陷和奥罗波罗斯的中空结构可能需要复杂的凹多边形拆分，建议初期碰撞判定用外包围凸多边形近似，仅在视觉渲染上表现凹陷。
