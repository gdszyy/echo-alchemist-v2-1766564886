# 模块专用文档：运动学与动画配置模块 (精简动画版)

## 1. 模块概述
本模块负责为生物配置待机（Idle）、受击（Hit）、移动（Move）三种核心动画。针对“面向屏幕”和“向前移动”的需求，动画管线进行了极致精简，以提升在 120 像素空间内的表现力。

## 2. 核心技术要素

### 2.1 核心动画逻辑
*   **移动 (Move)**：仅配置纵向（Y 轴）推进的步态。由于生物面向屏幕，重点表现肢体的上下起伏和透视缩放，而非侧向位移。
*   **待机 (Idle)**：配置微小的呼吸起伏和重心晃动，确保生物在静止时仍有生命感。
*   **受击 (Hit)**：配置瞬间的后退位移与全身骨骼的“受击回弹”逻辑。利用预设的受击节点产生高频、衰减的震荡效果。

### 2.2 骨骼与 DoF 精简
*   **非必要关节锁定**：锁定所有与侧向移动、转向相关的关节自由度，仅保留驱动三种核心动画的 DoF。
*   **自动化蒙皮优化**：针对 120 像素显示，优化蒙皮权重，防止在大幅度受击动作时出现像素级的几何拉伸。

### 2.3 动画语义注入
*   **触发器预设**：在输出资产中内嵌 `onIdle`、`onMove`、`onHit` 动画状态机，确保与下游游戏逻辑无缝对接。

## 3. 输入与输出
*   **输入**：极简 Lowpoly 网格、精简骨架、动画剪辑模板。
*   **输出**：带三种核心动画状态的 Lowpoly 资产。
