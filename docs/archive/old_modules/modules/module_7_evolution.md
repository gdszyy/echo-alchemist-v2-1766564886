# 模块专用文档：进化与反馈循环模块 (场景适配版)

## 1. 模块概述
本模块在 120x120 像素空间的虚拟沙盒中评估生物的表现。进化目标从“全能生存”转向“**特定场景下的视觉与功能最优解**”。

## 2. 核心技术要素

### 2.1 场景特定适应度函数
*   **空间利用率评估**：评估生物在 120x120 空间内的视觉占比，剔除过小或过大的个体。
*   **正面视觉评分**：利用图像识别算法评估生物在正面视角下的特征辨识度（如眼睛、肢体轮廓是否清晰）。
*   **移动效率测试**：仅测试生物向前移动的平稳度与速度。

### 2.2 动画表现力评估
*   **受击反馈度**：评估生物在受击动画下的视觉冲击力（如形变是否明显但不过分）。
*   **待机自然度**：评估呼吸动画的节奏感。

### 2.3 进化压力调整
*   **像素化鲁棒性**：在评估过程中引入低分辨率采样，优先筛选出那些在像素化后依然保持美感的基因型。

## 3. 输入与输出
*   **输入**：120 像素沙盒环境、视觉辨识度目标、精简动画模板。
*   **输出**：针对 120 像素空间优化的生物参数集。
