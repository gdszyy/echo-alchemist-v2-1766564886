# 模块专用文档：功能性肌肉发生模块 (视觉特征版)

## 1. 模块概述
本模块根据“向前移动”的动力学需求生成肌肉体积。由于生物面向屏幕，肌肉生成策略从“全解剖模拟”转向“**视觉特征模拟**”，重点强化正面可见的肌肉轮廓。

## 2. 核心技术要素

### 2.1 推进肌群强化
*   **核心动力源生成**：重点模拟负责向前推进的肌群（如大腿前侧、胸部/肩部推进肌）。
*   **PCSA 视觉加权**：在计算肌肉截面积时，增加正面视角的权重系数，使生物看起来更加强壮有力。

### 2.2 动画响应式肌肉
*   **待机呼吸感**：在胸腔区域生成具有特定弹性系数的肌肉，用于模拟待机时的微弱起伏。
*   **受击震荡（Hit Jiggle）**：在躯干肌肉中嵌入非线性弹簧约束。当触发“受击”信号时，肌肉会产生明显的瞬间形变与回弹，增强打击感。

### 2.3 120 像素空间适配
*   **体积紧凑化**：利用投影动力学将肌肉紧紧包裹在骨骼周围，防止肌肉体积超出 120x120 的边界。
*   **轮廓清晰度优化**：在肌肉边缘生成更强的梯度场，为后续的 Lowpoly 离散化提供明确的硬边引导。

## 3. 输入与输出
*   **输入**：物理骨架、向前移动矢量、受击反馈参数。
*   **输出**：针对正面视角优化的功能性肌肉体积场。
