# Elite Golem Affix Bases Pass 6

Pass 6 is the current four-base-attribute direction for elite golem affix art.
It is not wired into runtime code yet.

## Scope

- `armorSpore`: asymmetrical natural spore armor growth, muted green.
- `jump`: lighter agile silhouette, reverse-bow legs, blue propulsion struts.
- `haste`: yellow-gold airflow channels, ducted armor, swept streamlining.
- `berserk`: asymmetric overcharged body, red cracked core, broken restraint feel.
