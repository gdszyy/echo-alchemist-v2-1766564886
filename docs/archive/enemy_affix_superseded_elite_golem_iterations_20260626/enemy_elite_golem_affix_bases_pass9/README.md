# Elite Golem Affix Bases Pass 9

Pass 9 keeps the pass7/pass8 front-facing cropped elite golem body language, pushes the head larger again, and differentiates each base affix through head/eye shape rather than color alone.

## Head Language

- `armorSpore`: oversized organic head with one green cyclops glowing eye.
- `jump`: oversized lighter helmet with two blue glowing eye lenses.
- `haste`: oversized streamlined head with one horizontal yellow-gold visor eye.
- `berserk`: oversized cracked head with jagged red rage eye slits.

## Output

- Transparent exports: `elite_golem_<affix>_front_256_pass9.png`
- Gameplay readability exports: `elite_golem_<affix>_front_128_pass9.png`
- Runtime composites: `assets/sprites/enemies/composites/enemy_elite_golem_<affix>_1x1_pass9_idle.png/.json`
- Review sheet: `review_elite_golem_affix_bases_pass9_contact_sheet.png`

## Runtime Scope

Only the four single-affix elite golem keys point to pass9. Multi-affix combination assets remain on pass7 until the head/eye language is approved.
