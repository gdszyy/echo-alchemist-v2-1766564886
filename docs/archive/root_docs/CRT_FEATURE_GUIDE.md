# CRT显像管效果使用指南

## 功能简介

Echo Alchemist现已支持复古CRT显像管视觉效果，为游戏带来怀旧的电视机观感体验。该效果包括经典的扫描线、四周暗角、微弱闪烁等视觉元素，完美重现老式阴极射线管显示器的独特魅力。

## 如何使用

### 开启/关闭效果

在游戏界面的右上角工具栏中，您会看到一个📺(电视机)图标按钮。点击该按钮即可切换CRT效果的开关状态。

**按钮状态指示**:
- **激活状态**: 按钮呈现琥珀色高亮，带有发光效果
- **关闭状态**: 按钮显示为普通灰色

### 效果特性

当CRT效果开启时，您会在整个游戏画面上看到以下视觉特征：

**扫描线**: 横向的细密线条覆盖整个屏幕，模拟电子束逐行扫描的效果。这些线条间隔为4像素，透明度经过精心调校，既能体现复古质感又不影响游戏内容的清晰度。

**晕影**: 屏幕四周会出现渐进式的暗角效果，这是老式CRT显示器的典型特征。边缘亮度衰减将玩家的视线自然引导到屏幕中心，增强游戏沉浸感。

**微闪**: 屏幕会产生极其微弱的亮度波动，模拟电压不稳定或电子枪老化的效果。这种闪烁非常轻微(透明度仅在0.92-0.95之间变化)，不会引起视觉疲劳或影响游戏体验。

### 设置持久化

您的CRT效果偏好设置会自动保存到浏览器本地存储中。这意味着：

- 关闭浏览器后重新打开，效果状态会保持您上次的选择
- 刷新页面不会重置设置
- 每个浏览器独立保存设置(Chrome和Firefox的设置互不影响)

**默认行为**: 首次访问游戏时，CRT效果默认为开启状态。

## 技术特点

### 高性能实现

CRT效果采用纯CSS技术实现，具有以下性能优势：

- **零CPU开销**: 所有视觉效果由浏览器原生CSS引擎处理
- **GPU硬件加速**: 透明度动画和混合模式由显卡GPU加速渲染
- **极低内存占用**: 仅使用单个DOM元素作为遮罩层
- **不影响帧率**: 游戏运行流畅度完全不受影响

### 完全不影响交互

CRT效果层使用了`pointer-events: none`属性，这确保了遮罩层完全透明于鼠标和触摸事件。您可以像往常一样点击按钮、拖动元素、操作游戏，CRT效果不会拦截任何交互操作。

### 浏览器兼容性

该功能使用的所有CSS特性均为现代浏览器标准，支持：

- Google Chrome 90+
- Mozilla Firefox 88+
- Microsoft Edge 90+
- Safari 14+
- 以及其他基于Chromium的浏览器(Opera, Brave等)

## 常见问题

### Q: CRT效果会影响游戏性能吗？
A: 不会。该效果采用纯CSS实现，由浏览器原生优化，对游戏帧率和响应速度没有任何负面影响。

### Q: 我可以调整效果的强度吗？
A: 当前版本提供开/关两种状态。效果强度已经过精心调校，在复古感和可用性之间达到最佳平衡。

### Q: 为什么我看不到效果？
A: 请确认：
1. 右上角的📺按钮是否显示为琥珀色高亮(激活状态)
2. 您的浏览器是否为较新版本
3. 尝试刷新页面或清除浏览器缓存

### Q: 效果会在移动设备上显示吗？
A: 会的。CRT效果在移动设备上同样生效，且不会影响触摸操作。

### Q: 我的设置会在不同设备间同步吗？
A: 不会。设置保存在浏览器本地存储中，不同设备需要分别设置。

## 技术实现细节

对于开发者和技术爱好者，以下是实现的核心技术要点：

### CSS实现
```css
#crt-overlay {
    position: fixed;
    width: 100vw;
    height: 100vh;
    pointer-events: none;
    z-index: 9999;
    
    /* 扫描线 */
    background: linear-gradient(
        to bottom,
        rgba(255, 255, 255, 0),
        rgba(255, 255, 255, 0) 50%,
        rgba(0, 0, 0, 0.2) 50%,
        rgba(0, 0, 0, 0.2)
    );
    background-size: 100% 4px;
    
    /* 晕影 */
    box-shadow: inset 0 0 100px rgba(0, 0, 0, 0.9);
    
    /* 混合模式 */
    mix-blend-mode: multiply;
}
```

### JavaScript控制
```javascript
const crtBtn = document.getElementById('crt-btn');
const crtOverlay = document.getElementById('crt-overlay');
let isCrtOn = localStorage.getItem('ea_crt_enabled') !== 'false';

crtBtn.addEventListener('click', () => {
    isCrtOn = !isCrtOn;
    localStorage.setItem('ea_crt_enabled', isCrtOn);
    updateCrtVisuals();
});
```
