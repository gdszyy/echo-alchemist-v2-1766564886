# Archived Enemy Affix Wrong Direction Assets

这些素材来自 2026-06-25 的敌人词条美术探索，但方向已被否定，因此从可接入资产目录归档到这里，避免误导后续接入。

## 归档原因

- `armorSpore`、`jump`、`haste`、`berserk` 应用于精英敌人时，主体应是正视图精英魔像，而不是方块、纹章、基座或普通敌人基座变体。
- 早期版本把“资产画布保持正方形”误读成“敌人主体是方块”，不应继续作为设计参考。
- 后续有效方向为 `assets/sprites/enemies/elites/golem_affix_combos/pass2/`：正视魔像主体，`armorSpore` 绿、`jump` 蓝、`haste` 黄、`berserk` 红。

## 归档内容

- `assets_sprites_enemies_variants_pass1/`：普通基座变体方向，已废弃。
- `assets_sprites_enemies_variants_pass2/`：普通基座变体修正版，已废弃。
- `assets_sprites_enemies_elites_affix_combos_pass1/`：方块化精英组合资产，已废弃。
- `docs_design_concepts_enemy_affix_variants_pass1/`：对应 pass1 评审图与说明，已废弃。
- `docs_design_concepts_enemy_affix_variants_pass2/`：对应 pass2 评审图与说明，已废弃。
- `docs_design_concepts_enemy_elite_affix_combos_pass1/`：对应方块化精英组合评审图与说明，已废弃。
