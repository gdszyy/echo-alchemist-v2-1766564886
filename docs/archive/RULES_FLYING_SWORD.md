# 子母剑系统规则 (Flying Sword System)

子母剑（Flying Sword）是一种高级进化属性，通过特定的属性组合获得，具有自动追踪和连续打击的能力。

## 1. 获取与升级规则

子母剑属性主要通过收集阶段的“变异”或“升级”获得：

- **变异 (Mutation)**: 拥有 `pierce` (穿透) 属性的弹珠撞击 `pierce` 类型的钉子时，有概率变异为 `flying_sword`。
- **升级 (Upgrade)**: 拥有 `flying_sword` 属性的弹珠撞击 `flying_sword` 类型的钉子时，提升其等级。

## 2. 核心战斗机制

### 2.1 触发与生成
- 当带有 `flying_sword` 属性的主弹丸（母剑）击中敌人时，会触发子剑生成逻辑。
- 如果主弹丸仍有穿透次数（Pierces），则在击中位置生成一颗**子剑 (Son Sword)**。

### 2.2 子剑行为模式
子剑生成后会经历以下生命周期：
1. **启动延迟**: 生成后有短暂的随机延迟，增加视觉上的层次感。
2. **自动索敌 (Hunting)**: 自动寻找屏幕内最近的活跃敌人作为目标。
3. **冲刺打击 (Dashing)**: 以极高速度向目标冲刺，穿过敌人并造成伤害。
4. **连续攻击**: 子剑的攻击次数由 `multicast` 属性决定（基础次数为 1）。
5. **回收/消失**: 攻击次数耗尽后，子剑会消失或尝试返回。

## 3. 等级与视觉表现

子母剑系统分为三个等级，每个等级具有不同的视觉特征：

| 等级 | 颜色 | 视觉描述 |
| :--- | :--- | :--- |
| **Lv.1** | 蓝色 (`#0ea5e9`) | 基础子母剑，提供基础的追踪打击。 |
| **Lv.2** | 紫色 (`#6366f1`) | 进阶子母剑，伤害与速度提升。 |
| **Lv.3** | 红色 (`#f43f5e`) | 终极子母剑，具有最强的攻击频率和破坏力。 |

## 4. 属性交互
- **穿透 (Pierce)**: 决定了母剑在一次飞行中能生成多少颗子剑。
- **多重射击 (Multicast)**: 决定了每颗子剑能够连续打击目标的次数。
