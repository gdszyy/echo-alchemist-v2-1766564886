## 1. 任务描述

将 JavaScript 命运轮盘 (FortuneWheel) 迁移到 Godot 4.x GDScript。

## 2. 源文件

`src/entities.js` (252-540 行)

## 3. 需要迁移的功能

| 功能 | 行号范围 | 描述 |
|:---|:---|:---|
| `constructor` | 253-273 | 初始化轮盘参数和图标映射 |
| `spin` | 275-345 | 启动旋转，构建扇区 |
| `update` | 347-364 | 更新旋转角度和摩擦力 |
| `getCurrentSlice` | 366-371 | 获取当前指针指向的扇区 |
| `finalizeResult` | 373-380 | 确定最终结果并触发回调 |
| `draw` | 382-539 | 绘制豪华轮盘（外框、灯泡、扇区、指针） |

## 4. 轮盘特点

1. **动态扇区**：根据玩家收集的属性动态生成
2. **权重算法**：扇区大小 = 基础权重 × (1 + 层数 × 0.5)
3. **奖励算法**：中奖层数 = ceil(当前层数 × 0.5)
4. **豪华视觉**：
   - 金色外框渐变
   - 跑马灯灯泡效果
   - 中心装饰星星
   - 红色指针

## 5. 技术要求

1. 使用 Godot 4.x 的 `Node2D` 作为基类
2. 使用 `_draw()` 方法绘制轮盘
3. 使用信号机制替代回调函数
4. 实现平滑的旋转和减速动画

## 6. 输出目录
