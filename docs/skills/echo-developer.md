# Echo Developer (Echo Alchemist V2 统一开发者)

本 Skill 是 Echo Alchemist V2 项目的统一开发入口。为了保持上下文的精简和信息的实时准确，本 Skill 采用**纯索引指引型**设计，与项目建立了一致的索引契约。在执行任何代码修改任务前，你**必须**按照以下指引读取项目仓库中的最新规范文档。

## 核心索引规范 (必须严格遵循)

1. **克隆/拉取仓库**
   - 目标仓库：`gdszyy/echo-alchemist-v2-1766564886`
   - 必须在执行任何修改前获取最新代码，确保基于最新架构进行开发。

2. **定位全局索引入口 (必读)**
   - **必须使用 `file` 工具读取仓库根目录下的 `AGENTS.md`。**
   - 找到其中的 **"快速导航与核心入口规范 (Quick Navigation)"** 章节。
   - 按照该节的指引，读取项目中最新的架构状态、防坑指南 (`.cursor/rules/global.md`) 以及待办进度大盘 (`TODO.md`)。

3. **读取模块专属规范 (按需读取)**
   - 根据当前任务涉及的模块，在 `AGENTS.md` 的“子模块规范文档索引”指引下，读取 `.cursor/rules/` 目录下对应的 `*.md` 规范文件。

4. **执行代码修改与文档同步**
   - 遵循 `AGENTS.md` 中的“智能编辑策略决策树”进行代码修改。
   - **关键要求**：任何对代码核心逻辑、API、架构或状态管理的修改，**必须在同一个 Commit 中同步更新**对应模块的规范文档（`.cursor/rules/*.md`）。

5. **历史文档归档清理**
   - 在开发过程中，如果发现项目根目录或活跃文档区存在过期的设计方案或历史更新文档，必须主动将其移动到 `docs/archive/` 目录，保持文档库的整洁。

6. **提交交付物**
   - 提交 Git Commit（确保代码与文档同步更新）。
   - 如果任务由多 Agent 协作系统分配，请按照协调者的要求汇报进度并提交交付物。

---

**注意：** 本技能不再硬编码任何具体的架构细节、文件行数或禁止行为清单。所有的真理来源（Single Source of Truth）均以仓库中的 `AGENTS.md` 和 `.cursor/rules/` 目录下的文档为准。
