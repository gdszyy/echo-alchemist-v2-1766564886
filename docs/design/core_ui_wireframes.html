内容标注

核心目标确保中间长方形安全游戏区稳定可玩；两侧只做沉浸装饰和轻量悬浮信息。
常驻信息顶部战斗 HUD、底部发射器子弹信息。态势摘要不独立占条，只作为顶部胶囊；技能/符文/词条作为左右悬浮 UI。
即时反馈命中、克制、护盾、暴击、穿透、弹射等反馈贴近敌人或弹道出现，避免挤进顶部栏。
美术资产左右侧场景装饰、中央安全区边框、底部炼金发射台、发射器 V3、属性球轨道、敌人足迹、状态短标签底板。
态势必要性需要保留“防线风险”这个判断，但不需要一整条态势栏。敌人数/Boss/剩余弹药只在高压或需要决策时以胶囊显示。
底部禁区底部理论上不展示敌人，可承载发射器和当前子弹信息；需要与失败线/防线语义明确分离。

P0 细化：战斗主界面组件规格

本节是第一优先级的可执行设计：先把战斗页的固定信息、条件信息、反馈信息和美术资产边界定下来。实现时先按这张表做，不再额外扩张 UI 区域。

组件优先级

顶部战斗 HUD 默认字段：阶段名、回合数、护盾/生命类生存资源、局内资源、暂停/设置。 条件胶囊：防线风险常驻；敌人数、Boss、弹药余量只在高压、Boss 存在、弹药低于阈值时出现。 禁止：独立态势条、长句提示、超过一行半的胶囊堆叠。
核心游戏矩形 只承载战斗判定：敌人、弹丸、Peg、掉落物、状态短标、伤害数字、弹道反馈。 需要明确边界线和防线位置。背景应低对比，不出现高亮装饰图案。 敌人不得进入左右装饰区和底部发射器区。
左右场景装饰 左侧建议放炼金管线、液体刻度、伤害统计入口、符文充能。 右侧建议放炉壁、机械臂、SP/技能组、临时加成。 装饰必须比敌人和弹丸暗，悬浮 UI 采用半透明小面板。
底部发射器区 固定展示当前子弹：主属性、伤害、形态、连射/装填。 发射器本体承担瞄准、蓄力、属性球轨道和装填反馈。 这里是非敌人区，可以更厚重、更有仪式感，但不能遮挡发射轨迹起点。
即时反馈 命中反馈贴近事件源：伤害数字 + 最多 2 个短标签。 优先级：屏障/护盾 > 暴击 > 克制/有效 > 穿透/弹射 > 温度/毒素。 反馈消失后进入伤害统计，不常驻在战场。

状态显示规则

默认状态顶部只显示防线稳定、回合、护盾、资源；底部显示下一发四项读数；左右悬浮 UI 收起到紧凑态。
高压状态顶部防线胶囊变为压线/危险；敌人数/Boss 胶囊出现；左右悬浮 UI 可显示临时警示，但不进入中央游戏矩形。
瞄准状态底部发射器强化显示角度、弹道预览、装填格；顶部 HUD 不扩张；左右悬浮 UI 降低透明度，避免干扰瞄准。
命中爆发中央矩形内出现伤害数字和短标签；发射器可短暂脉冲；不弹出大面积遮罩。
回合结束敌人行动和奖励掉落仍在中央矩形内完成；选择/遗物出现时才进入蒙版 + 悬浮卡片。

P0 资产切分

必须先做顶部 HUD 底板、中央安全区边框、防线标记、底部发射器工作台、发射器本体、四项读数小格。
随后补强左右场景装饰、符文充能小面板、技能/SP 小面板、状态短标签底板、伤害数字样式。
暂缓复杂粒子、全屏高光、额外镜头运动、会改变战斗判定区域的装饰结构。

比例与禁区标注

顶部规则顶部状态与态势摘要合并，不再拆成两条。默认只显示防线风险，敌人数/Boss/弹药余量可作为胶囊补充。

落地优先级摘要

P0合并顶部战斗 HUD，固定竖屏核心游戏矩形、底部非敌人发射器区、左右场景装饰与悬浮 UI 边界。
P1所有选择类统一为蒙版 + 悬浮卡片：弹珠、遗物、商店购买、真理之书详情。
P2沉浸资产：左右场景装饰、底部发射器工作台、奖励飞入、敌人 Sprite、Boss 专属形象。
