## 1. 诊断：为什么现在的钉板没意义

S2 实现里采集弹珠只产一种「能量」，元素钉对它没有区别。打哪都一样，钉板沦为「点一下拿钱」。

**要恢复的玩家决策**：这一波我缺什么元素 → 往钉板上这种元素多的地方打。

## 2. 两类资源：元素材料 + 电力

### 2.1 元素材料（建造 / 升级的「料」）

- 采集弹珠撞到**元素钉**，就收集该元素材料。钉板上**只有火钉（红）和冰钉（蓝）**，**不出现雷钉**（用户 2026-10-22 决定）。
- 撞普通灰钉不给材料，只给电力（§2.2）。
- **雷 ⚡ 材料只有两个来源**（延续老方案「火 + 冰 = 雷」）：
  1. **火冰叠冲**：同一颗采集弹珠在一次下落中既撞到火钉又撞到冰钉，就按现有的弹珠合成规则把一份火和一份冰冲成一份雷。弹珠路线因此有了「跨过红区和蓝区」的追求。
  2. **电力合成**：工厂里用电力直接合成雷（§3.2 的「雷能合成器」，原「雷能合成器」改为用电而不是消耗火冰）。
- 毒、风等高级材料后续也由工厂合成，不直接挖。
- **晶核 💎** 保留为稀有料：来自钉板晶脉、精英、Boss，用于高阶配方。
- **每波重排**：每次挖矿前随机重排元素钉的分布，比如这波左侧火多、右侧冰多，发射前可见。玩家要按需求瞄准，钉板因此每波都有决策。

### 2.2 电力（让工厂运转的「电」）

- **来源**：每次碰钉都产电（任何钉都算），再加上发电类设备。
- **电力是每波的运转预算，不是存款**：
  - 每波挖矿得到的电，加上上波电池里的余电（不超过电池容量），就是这一波工厂可用的总电力。
  - 每台设备有**每波耗电**。总耗电超过可用电力时，按玩家设定的优先级从低往高**停机**，停机设备在战斗中不工作、显示熄灭。
  - 用不完的电存进电池，超出容量的作废。
- **目的**：钉板每波都要「挖够电」。设备越多越耗电，单纯囤料没用，还得有电才能让它们转起来，和 Dome Keeper「矿要运回去才算数」是同一种张力。

> 资源一览：🔥 ❄ ⚡（材料）＋ 💎（稀有）＋ 🔋 电力。顶栏常驻显示 5 个数。

## 3. 自动化工厂

### 3.1 工厂 = 战斗面板底部的那一排空位

- 屏幕底部的**工厂带**有 **4 个空位**（用户 2026-10-22 定：手机宽度下保持 24px 设备清晰度；开局 2 个可用，另 2 个需要先造出「扩建平台」设备）。主炮固定在工厂带中央，左右各 2 个空位。
- **空位就是战斗面板上的位置**：在第 2 个空位放了炮台，战斗时炮台就画在第 2 个位置、从那里朝上开火。放发电机，那个位置就显示发电机在转。
- 工厂带全程可见（挖矿、工厂、守卫三个阶段都在），是玩家的「家」和记忆锚点。

### 3.2 设备分两类

| 类别 | 例子 | 在战斗中 |
|---|---|---|
| **前线设备** | 炮台、冰霜塔、雷击塔、护盾发生器 | 自动开火 / 生效（冷却按回合） |
| **后勤设备** | 发电机、电池、雷能合成器、弹药工坊 | 不开火；提供电力、转换材料、产出一次性道具 |

**雷能合成器**是「自动化」的核心例子：每波自动用电力合成雷，每 4 电 → 1⚡（Lv2 起 3 电 → 1⚡）。它和「火冰叠冲」共同构成雷的两条来源：挖得巧可以省电，电多可以直接买雷。毒、风等高级材料也由类似设备合成。

### 3.3 解锁的是设备图纸，不是空位

- 开局只有 3 张图纸：**炮台、发电机、电池**。
- 之后每波结束、每个 Boss 击杀，从 3 张新图纸里选 1 张。这是 Dome Keeper 的「遗物/科技」节奏，替代原来的「设施位解锁」。
- 空位扩展本身也是一张设备图纸（「扩建平台」），而不是单独的解锁项。

### 3.4 配方（夹具数值）

| 设备 | 建造 | 每波耗电 | 作用 |
|---|---|---|---|
| 炮台 | 🔥3 | 2 | 打最前的敌人，伤害 6 |
| 冰霜塔 | ❄3 + 🔥1 | 3 | 每 3 回合冻结前排 1 个 |
| 雷击塔 | ⚡2 + ❄1 | 3 | 每 2 回合连锁 3 个 |
| 护盾发生器 | ❄2 + ⚡1 | 2 | 每 2 回合 +1 护盾（上限 3） |
| 发电机 | 🔥2 + ❄2 | 0 | 每波 +6 电 |
| 电池 | ❄2 | 0 | 电池容量 +10 |
| 雷能合成器 | 🔥2 + ❄2 | 按产量 | 每波把电力转成雷：4 电 → 1⚡（最多 3⚡/波） |
| 弹药工坊 | 🔥2 + ⚡2 | 2 | 每 2 波产出 1 个随机一次性道具（放进道具格） |
| 扩建平台 | 💎1 + 🔥2 + ❄2 | 0 | 解锁 1 个空位（最多到 4） |

- **升级**：同一台设备升 Lv2 消耗同配方的 1 倍，Lv3 再加 💎1。升级提升作用，也提升耗电。
- **主炮升级也用元素**：伤害 +1 = 🔥2，射速 +1 = ⚡3，弹道 +1 = ❄2，逐级加价。「不同元素买不同东西」由此成立：缺火就升不了伤害、造不了炮台。

### 3.5 一次性道具

不再在商店里直接买，改由**弹药工坊**自动产出，或在工厂界面用材料手工合成（炸弹 🔥2、急救结界 ❄2、时停 ⚡2 + ❄1）。

## 4. 每波流程（替换 v1 §7）

| 阶段 | 发生什么 | 玩家决策 |
|---|---|---|
| **挖掘** | 钉板在中央区域；元素分布本波重排后可见；采集批落下，撞钉产电产料，落入底部料斗，料斗就是工厂带的进料口，资源「掉进家里」 | 采集批瞄向缺的元素；炼成弹珠单独瞄 |
| **工厂**（原整备） | 工厂带展开成工厂界面；显示本波电力预算与耗电、材料、可建图纸、空位 | 建造、升级、拆除、调整停机优先级、升级主炮；点「开战」 |
| **守卫** | 中央区域换成战场；工厂带收回底部，设备在各自空位上工作，没电的显示熄灭 | 主炮瞄准、换炼成弹、用道具 |
| **波后** | 选 1 张新图纸（Boss 波后改为 Boss 奖励 + 遗物） | 三选一 |

## 5. 复杂度检查

- **新增概念**：3 种材料 + 晶核 + 电力预算 + 配方 + 图纸三选一。
- **抵消项**：去掉 v1 的设施位解锁、道具商店、挖矿升级四项、商人。
- **逐波解锁**：
  - 第 1 波只有 🔥 和电，图纸只有炮台和发电机。
  - 第 2 波出 ❄ 和电池。
  - 第 3 波开始提示「火冰叠冲出雷」，并出雷能合成器图纸。
  - Boss 后出 💎 和扩建平台。
- **风险**：耗电与停机优先级是新的认知负担。首版默认「最后建造的先停」，玩家可以不碰优先级。试玩时观察玩家是否理解为什么设备熄灭。
