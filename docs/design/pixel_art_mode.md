## 0. 结论先行

1. **一个像素网格**：主画布后备缓冲 = 美术像素（约 288 宽，每美术像素整数个设备像素）；世界、特效、HUD 全画进同一张缓冲；PixiJS 在像素模式下不初始化，特效走 Canvas 2D 后备路径。
2. **一套材质**：磨石（结构/敌人）、黄铜（只用于可交互与重要框线）、晶体（嵌入式核心与资源）、能量（元素发光，不描边）。光源左上，描边统一 INK。全部由代码程序化绘制，不复刻旧位图。
3. **局内 HUD 改为画布即时绘制**：每帧直读游戏状态（"切阶段才刷新 / 两处数值不一致"从机制上消失）；透明 DOM 热区承担点击、键盘焦点与读屏，复用原按钮处理函数。
4. **菜单仍是 DOM**，但外观换成与画布同源的像素组件（代码生成的九宫格 → CSS 变量），同一像素尺度 `--px`；Tailwind 颜色统一映射到调色板；文字里的彩色 emoji 换成点阵图标。
5. **一个概念一个名字、一个图标、一个颜色**（§3），简体中文；术语以项目已有的 `UI_TERMINOLOGY`（`src/systems.js`）为准。
6. **像素模式不加载任何旧位图**：画布上的敌人、首领、背景、墙、发射器，以及菜单里的遗物、符文、弹珠、属性、词条、技能、首领预览、掉落胶囊——全部由代码程序化绘制（§6.2）；框体类旧图（九宫格框、面板底）一律换成像素组件。旧的自动像素化副本（`assets/px/`）已删除。
7. 位图模式保留（`?art=bitmap` 或暂停菜单「像素画风」开关），行为与改造前一致。

## 2. 视觉系统

### 2.1 像素尺度
- 逻辑坐标仍是 CSS 像素（游戏逻辑零改动）；`computePixelLayout`：`k = round(cssW·dpr / 288)`（每美术像素 k 个设备像素），缓冲 = `round(cssW·dpr / k)`；可用 `?pxw=` 临时调目标宽度。
- 手机 430×765@2x → 287×509（1 美术像素 = 1.5 CSS 像素）；桌面 480 宽@1x → 240×427。
- 屏幕震动吸附整美术像素；钉盘的 CSS 3D 倾斜在像素模式下关闭（透视会把像素网格重采样成梯形）。

### 2.2 调色板（`src/pixel/palette.js`）
每条色阶暗→亮，暗部偏冷、亮部偏暖；新增颜色必须整条色阶一起加。

| 色阶 | 用途 |
|---|---|
| slate | 场景结构、面板、墙体、文字灰阶 |
| stone | 敌人基座（暗灰黑曜石） |
| brass | **只用于**可交互元素与重要框线（按钮、选中、精英扣带、首领冠带） |
| fire / ice / volt / venom / mint / cyan / blood / arcane / rose | 元素、状态与机制色（§3.3） |

像素模式启动时 `applyPixelPaletteToConfig` 把 `CONFIG.ui.attributeDisplay` 与 `CONFIG.colors.mat*` 等统一到这些色阶，仍走矢量的特效与 DOM 属性标签自动同色。

### 2.3 材质画法（`src/pixel/materials.js`）
- **磨石**：倒角 1px，左上亮两级、右下暗两级，块面两档低频明暗，稀疏砂点，裂纹带 1px 下亮边。
- **黄铜**：条带上亮下暗，铆钉 2×2 左上亮。
- **晶体**：暗缘 → 主体 → 左上亮面 → 1px 高光点；嵌在圆/方石槽里。
- **能量**：元素色阶亮端，不描边；像素模式下 `shadowBlur` 被钉为 0，线宽至少 1 美术像素。

### 2.4 文字
| 层级 | 字体 | 用途 |
|---|---|---|
| 数字读数 | 代码点阵 5×7（`src/pixel/pixel_font.js`）+ 1px INK 外框 | 血量、伤害、计数、倒计时 |
| 角标 | 点阵 3×5 | 层数、等级、倍率 |
| 中文 | Fusion Pixel 12px（OFL，`assets/fonts/`），整数倍字号、整像素落点 | 标签、名称、菜单正文；画布 `fillText/strokeText/measureText` 被统一接管 |

## 6. 菜单与弹层
