# Elite Golem Affix Combos Pass 12

Pass 12 regenerates the 11 cross-affix elite golem combo assets from the approved base language:

- `armorSpore`: green organic spore curves and cyclops glow.
- `jump`: blue compact propulsion and blue lens accents.
- `haste`: pass11-style yellow visor, rounded shoulders, and streamlined limbs.
- `berserk`: red cracks and one burning eye.

## Output

- Transparent exports: `elite_golem_<combo>_front_256_pass12.png`
- Gameplay readability exports: `elite_golem_<combo>_front_128_pass12.png`
- Runtime composites: `assets/sprites/enemies/composites/enemy_elite_golem_<combo>_1x1_pass12_idle.png/.json`
- Source generated frames: `source_generated/<combo>_generated_pass12_source.png`
- Review sheet: `review_elite_golem_affix_combos_pass12_contact_sheet.png`

## Runtime Scope

All 11 multi-affix elite golem combo keys now point to pass12. Single-affix keys remain split across pass10/pass11: `armorSpore`, `jump`, and `berserk` use pass10, while `haste` uses pass11.
