Design intent:

- Parent/base body for the `armorSpore`, `jump`, `haste`, and `berserk` elite golem variants.
- No yellow speed lines, blue thrusters, green spores, red cracks, shield bubble, regen marks, clone fragments, labels, or UI frame.
- Overlay-only affixes such as `shield` or `regen` must layer over this body and must not create a new body key.
