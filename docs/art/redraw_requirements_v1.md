- 日期：2026-10-22。用户要求：「重绘不是依葫芦画瓢，是根据原始素材的需求、定位、交互，摸清楚了再重绘一个更合适的」。

## 1. 普通敌人

**1×1 基础「炼金残渣」**：AABB。血量 `(5+4r)·1.08^r`。从网格上方 2 行入场。

- 50% 概率换上一个击杀 Boss 的随从轮廓：三角、菱形、六边、切角矩形、水滴、刀形平行四边形、锯齿五边。**这些轮廓同时是碰撞多边形，造型必须对上**（`src/spawn_system.js:2847-2960`）。

**多格原型**：一律是精英，血量 = 基础 × 格数（`spawn_system.js:3418-3655`）。

| id | 格 | 碰撞 | 造型必须说清的事 |
|---|---|---|---|
| bastion 堡垒 | 3×1 | AABB | 重甲，血 ×2、两回合才动一次；像一堵墙，暗示穿透 / 激光克它 |
| deflector 偏折 | 2×1 | 斜六边 | 偏折屏障（10% 血）只吸收反弹 / 穿透伤害；需要「屏障满」与「屏障破」两态 |
| echoSpire 回响塔 | 1×2 | 尖塔五边 | 转发邻居词条；需要「连着邻居」的视觉 |
| maw 巨口 | 2×2 | 缺角六边 | 吞噬相邻友军并继承血量和词条；需要「进食」状态 |
| prism 棱镜 | 1×3 | 长菱形 | 折射激光（50%） |
| hive 巢 | 2×3 | AABB | 每 2 回合孵化一只；需要「即将孵化」倒计时 |
| siege 攻城 | 3×2 | 八边 | 免冻；把前方阻挡链推进 1 行 |
| carrier 母舰 | 3×2，下中格是空舱 | 多边形 | 每回合在空舱投放极速 + 跳跃随从 |
| gravityCore 引力核 | 3×3 | 圆，r = 0.45 | 吸引 220px 内的子弹；要画出吸引范围 |

**词条**（`src/systems.js:831-940`、`src/config.js:559-632`）：每个词条用一个大的造型特征表达，不用文字徽章。

- 护盾 / 流彩护盾：外层甲片 / 流光外壳
- 极速：前倾轮廓 + 尾迹
- 再生：发光脉络
- 增殖：芽孢
- 狂暴：裂口发热
- 治愈：十字核心
- 吞噬：大口
- 跳跃：弹簧腿
- 活甲：可再生外壳
- 孢甲：背部孢囊
- 破障：钻头
- 偏折壳：旋转鳞片
- 能量甲：电容片
- 相位盾：半透明残影（每 3 回合熄一次）
- 过载反应堆：外露反应堆
- 低伤免疫：厚壳
- 符文携带：背上符文石

**通用状态**（`src/entities/enemy.js`）：命中白闪；温度 ≥34 / ≥67 / ≥100 三档发热；冻结；毒层；行动预告（telegraphing）；跳跃弧线；吞噬中；死亡。血量用**像素破碎**表达（四阶段裂纹，保护眼睛 / 核心 / 词条特征）。

## 2. 精英

- 至少带 1 个词条即为精英，入场有金色冲击波（`spawn_system.js:797-873`）。
- 精英保持 24×24，靠轮廓 + 词条造型区分，不靠变大。

## 3. Boss（8 个，代码实际 4×3 格）

- 通用规则：
  - 血量 < 20% 时狂暴（`src/config.js:677`）。
  - 每 3–4 回合移动一次。
  - 有破绽槽，打满后暴露 1 回合（承伤 ×1.35）。
  - 需要以下状态叠层：破绽 0 / 25 / 50 / 75、破、暴露、恢复。
- **轮廓必须等于碰撞**：现在 ouroboros 画大了 1.72 倍、devourer 1.22 倍、mikro 1.18 倍，要改掉。
- 各 Boss 的弱点就是像素破碎时最先掉、也是要瞄准的部位：

| Boss | 碰撞 | 机制要点 | 弱点部位 |
|---|---|---|---|
| ignis | 梯形 | 炉压到 45 触发流彩护盾；狂暴后溅火 | 胸口炉门 |
| glacies | 五边 | 跳跃 + 再生；霜缝缝合 3（狂暴 5）个敌人，霜缝要可见 | 腿关节、背缝 |
| mikro | 12 边椭圆 | 分裂 + 治愈；每个分身减伤 10% | 母核 |
| devourer | 8 点巨口 | 吞噬 + 护盾；每回合吸近 1 格；召唤奴仆 | 口腔 / 喉 |
| viridis | 大 Boss | 再生、治愈、活甲、孢甲；孢子开花槽到 18 | 树心 |
| tesla | 菱形，大 Boss | 场强到 36、导体最多 8 个、电击 | 相位核 |
| chimera | 五边，大 Boss | 左冷右热；每回合吞 2；召唤喂食者 | 反应堆 |
| ouroboros | 环形 | 6 个轨道挂件每回合轮转（aegis、graft、brood、stride、maw、surge），弱点随之轮换 | 当前挂件 |

## 4. 玩家侧

- **主炮**：
  - 要显示：瞄准方向、本回合剩余发数（2–5）、下一发是否已换成炼成弹（发光装填）。
  - 位置：工厂带中央。
- **工厂设备（新）**：
  - 前线：炮台、冰霜塔、雷击塔、护盾发生器。
  - 后勤：发电机、电池、雷能合成器、弹药工坊、扩建平台。
  - 每台都要表达：所在空位、是否通电（亮 / 熄）、冷却格、触发瞬间。
  - **现在设施在战场上没有实体，只有 HUD 字块**，重绘后要在空位上真实存在，攻击从设备本体发出。现在雷击塔是从 y = h − 110 的假点发电（`src/build_system.js:297`），要改掉。
- **防线 / 结界**：三态，琥珀待机、红色危险（敌人在 1.45 行内）、蓝色结界 N 层。
- **钉板**：
  - 普通灰钉（只给电）、火钉、冰钉（**无雷钉**）。
  - 采集弹珠、炼成弹珠。
  - 特殊槽：recall、multicast、split、relic。
  - 料斗（倍率 ×1 / ×2 / ×3，紧挨漏口的倍率最高）。
