# Echo Alchemist V2: 精英(紫色)与 Boss(红色) 视觉设计重构与头脑风暴方案

## 1. 现状分析与问题定位

在当前的 `enemy.js` 渲染管线中，虽然已经通过 Task A/B/D 等多次迭代增加了材质光泽、战损裂纹、呼吸缩放、边框脉冲光晕等增强效果，但精英（Elite）和 Boss 的视觉区分度仍然主要依赖于：
1.  **基础颜色（Base Color）**：普通 `#475569` (灰蓝) / 精英 `#581c87` (深紫) / Boss `#7f1d1d` (深红)。
2.  **边框颜色与宽度（Border）**：精英 `#facc15` (金色) 3px / Boss `#ef4444` (红色) 4px。
3.  **边框脉冲光晕（Border Pulse Glow）**：精英金色光晕（乘数 1.8） / Boss 红色光晕（乘数 2.5，周期缩短）。
4.  **专属装饰（Boss Decoration）**：Boss 有专门的 `_drawBossDecoration`，而精英没有专属的内部装饰或符号。

**存在的问题**：
*   **精英敌人的视觉特征单薄**：除了颜色变紫、边框变金外，精英敌人缺乏结构性的视觉标识（如专属王冠、核心宝石或特殊纹理），在词缀特效（如 shield 的浅蓝蜂巢、haste 的黄色残影）叠加后，紫色的基础色容易被掩盖，导致精英感不足。
*   **Boss 的压迫感局限于光效**：Boss 虽然有专属装饰，但红色的运用较为扁平。狂暴状态（Berserk）虽然有红色边框和粒子，但与 Boss 本身的红色基础色重叠，导致狂暴前后的对比度不够强烈。
*   **与词缀特征的融合度不够**：目前的词缀特效（Layer 3.5）对所有类型的敌人一视同仁。精英和 Boss 作为更强大的载体，其身上的词缀特效应该表现出更强的能量感或变异感（例如，精英的 shield 应该比普通的 shield 更厚重或有不同的几何结构）。

## 2. 重构目标

1.  **提升精英（紫色）的质感与辨识度**：赋予精英敌人独立于颜色的结构性视觉标识，使其在任何词缀组合下都能被一眼识别。
2.  **深化 Boss（红色）的压迫感与层次感**：通过材质变异、能量溢出和动态轮廓，增强 Boss 的视觉重量。
3.  **词缀特效的阶梯式渲染**：根据敌人类型（Normal / Elite / Boss），对同一种词缀特效进行差异化渲染，体现"宿主越强，词缀表现越狂暴"的设定。

## 3. 头脑风暴与设计方案

### 3.1 精英（紫色）设计重构：从"换色"到"晶化变异"

**设计理念**：紫色（`#581c87`）代表着虚空与高浓度能量。精英敌人不应只是被刷了一层紫漆的方块，而应该表现出被高维能量"晶化"或"变异"的特征。

**具体方案**：
*   **核心重构（Layer 3.8 新增 `_drawEliteDecoration`）**：
    *   **虚空晶核（Void Core）**：在精英敌人中心绘制一个缓慢旋转的菱形晶体（颜色为 `#c084fc` 到 `#a855f7` 的渐变），带有微弱的 `lighter` 模式发光。这是精英能量的源泉。
    *   **晶化外壳（Crystallized Shell）**：在基础纹理（Layer 1.5）之上，叠加一层不规则的多边形几何切面（使用半透明的 `#7c3aed`），模拟紫水晶的折射反光，使其看起来比普通敌人更坚硬。
*   **边框升级（Layer 5）**：
    *   将现有的单调金色边框（`#facc15`）升级为**流光金边**。在边框路径上添加一个随时间移动的高光点（线性渐变），模拟能量在装甲边缘流淌的效果。
    *   在顶部边缘添加两个小型的向上突起（类似于简化的王冠或犄角结构），改变其纯粹的矩形轮廓。

### 3.2 Boss（红色）设计重构：从"大红块"到"深渊熔炉"

**设计理念**：红色（`#7f1d1d`）代表着极端的危险、狂暴与毁灭。Boss 应该像一个随时会爆发的深渊熔炉，其外壳只是为了勉强束缚住内部狂暴的能量。

**具体方案**：
*   **材质重构（Layer 1.5 增强）**：
    *   **熔岩脉络（Magma Veins）**：在暗红色的基础外壳上，绘制动态的熔岩纹路（使用 `#ef4444` 到 `#f97316`）。这些纹路不是静态的，而是使用 `visualSeed` 和 `Date.now()` 驱动的柏林噪声（或简化的正弦波叠加）进行缓慢的明暗呼吸。
*   **轮廓与光环（Layer 6 增强）**：
    *   **深渊黑晕（Abyssal Aura）**：在红色的脉冲光晕（`borderPulseColorBoss`）之下，增加一层紧贴身体的纯黑/深红色极度模糊阴影（`shadowBlur: 30`, `shadowColor: #450a0a`），制造出一种吞噬周围光线的压迫感。
*   **狂暴状态（Berserk）视觉重做**：
    *   当 Boss 触发狂暴或温度过高时，原本的暗红色外壳开始"剥落"（通过改变基础颜色的 alpha 值或叠加黑色斑块），暴露出内部纯白/亮黄色的高能核心（使用 `lighter` 模式的强光晕）。
    *   现有的 `bossOverglowAlpha` 在狂暴时应伴随高频的随机闪烁（Flicker），而非平滑呼吸。

### 3.3 词缀特效的阶梯式演进 (Affix Escalation)

为了让词缀特征更好地配合敌人的质感，我们需要在 Layer 3.5 中根据 `this.type` 对词缀表现进行缩放：

*   **Shield（护盾）**：
    *   *Normal*：细线浅蓝六边形网格（现状）。
    *   *Elite*：六边形网格变粗，且交点处有高亮节点（Node Glow），网格颜色偏向紫蓝色（融合精英底色）。
    *   *Boss*：网格演变为实体化的能量装甲片（带透明度的多边形填充），受击时有碎片剥落效果。
*   **Regen（再生）**：
    *   *Normal*：底部向上的绿色液体波纹（现状）。
    *   *Elite*：波纹中夹杂着上升的绿色气泡（小圆圈），波纹边缘有高光描边。
    *   *Boss*：整个身体被绿色的生物脉络缠绕，脉络会像心脏一样有节奏地搏动（缩放）。
*   **Haste（极速）**：
    *   *Normal*：横向黄色残影线（现状）。
    *   *Elite*：残影线带有电弧（折线），颜色变为金紫色交织。
    *   *Boss*：身体两侧出现持续喷射的等离子尾迹（使用粒子系统或拖尾多边形），方向与运动方向相反。
*   **Clone（分身）**：
    *   *Normal*：中心淡紫色过曝叠加（现状）。
    *   *Elite*：身体内部出现重影（以 0.3 的 alpha 值在本体偏移几个像素的位置绘制本体的缩小版）。
    *   *Boss*：周围环绕着 2-3 个微小的浮动细胞器（小圆点，按轨道旋转）。

## 4. 实施路径 (Action Plan)

本次重构主要集中在 `src/entities/enemy.js` 和 `src/config.js`，属于**中型到大型修改**，需要谨慎操作以避免破坏现有的自适应性能系统（`PI-004`）。

**第一步：更新 `config.js`**
*   在 `CONFIG.enemyRender` 中添加精英专属装饰（如 `eliteCoreRadius`, `eliteCoreColor`）、流光金边参数（`eliteBorderFlowSpeed`）、Boss 熔岩脉络参数等。

**第二步：修改 `enemy.js` 基础渲染**
*   在 `draw()` 方法中新增 `_drawEliteDecoration` 的调用（插入在 Layer 3.8 附近）。
*   修改 Layer 1.5 或 Layer 3 的底色逻辑，为 Boss 注入动态的熔岩纹路。
*   修改 Layer 5 的边框绘制，为 Elite 添加流光高光点和突起轮廓。

**第三步：重构 `enemy.js` 词缀特效 (Layer 3.5)**
*   在 `shield`, `regen`, `haste`, `clone` 等词缀的绘制逻辑中，引入 `if (this.type === 'elite')` 和 `if (this.type === 'boss')` 的分支，实现上述的阶梯式渲染。

**第四步：同步规范文档**
*   更新 `.cursor/rules/entities.md`，记录新的渲染层级和精英/Boss 差异化视觉逻辑。
*   如有涉及性能开销的改动（如新增粒子或复杂渐变），更新 `.cursor/rules/performance.md` 和 `PI-004` 洞察。
