# Lowpoly PGC 生物生成项目架构设计 (v2.0 - 像素空间适配版)

## 1. 项目概述
本项目旨在构建一个针对特定显示环境（120x120 像素空间）优化的 Lowpoly 生物过程化生成系统。系统生成的生物主要面向屏幕，仅具备向前移动的动力学特征，并针对待机（Idle）、受击（Hit）、移动（Move）三种核心动画进行管线精简。

## 2. 核心架构模块划分 (针对性调整)

### 模块一：拓扑生成模块 (空间约束版)
*   **核心功能**：在 120x120 的虚拟包围盒内生成骨骼拓扑。
*   **调整重点**：引入**边界框裁剪（Bounding Box Clipping）**，确保生物肢体在生成时不超出空间限制；强化正面视觉特征的骨骼分布。

### 模块二：生物力学与物理验证模块 (正面视角版)
*   **核心功能**：验证生物在向前移动时的物理稳定性。
*   **调整重点**：侧重于**纵向平衡分析**（向前移动的惯性补偿）；根据 120 像素的显示精度，自动简化骨骼直径的异速生长计算。

### 模块三：功能性肌肉发生模块 (视觉特征版)
*   **核心功能**：基于向前移动的动力学需求生成肌肉。
*   **调整重点**：重点生成**正面可见肌群**（如胸肌、前肢肌肉）；针对“受击”动画，预留肌肉震荡（Jiggle）的物理参数。

### 模块四：隐式表面融合模块 (低分辨率优化版)
*   **核心功能**：将骨骼肌肉融合为 SDF 场。
*   **调整重点**：针对 120x120 的低分辨率显示，调整 SDF 采样率；优化平滑因子 $k$，确保在像素化后依然保留清晰的轮廓。

### 模块五：Lowpoly 离散化与风格化模块 (像素美学版)
*   **核心功能**：生成适合像素显示的 Lowpoly 网格。
*   **调整重点**：**极简面数控制**（Target Polycount < 500）；强化平直着色以在低分辨率下产生强烈的明暗对比。

### 模块六：运动学与动画配置模块 (精简动画版)
*   **核心功能**：配置待机、受击、移动三种动画。
*   **调整重点**：**DoF 极致精简**，仅保留驱动这三种动画的核心关节；自动生成针对“受击”反馈的骨骼回弹逻辑。

### 模块七：进化与反馈循环模块 (场景适配版)
*   **核心功能**：在 120x120 空间内评估生物表现。
*   **调整重点**：适应度函数改为评估“向前移动效率”与“正面视觉饱满度”。

## 4. 数据流向视图
1.  **输入**：120x120 空间约束 + 正面视角参数 + 基础蓝图。
2.  **处理层**：
    *   空间受限的骨骼生成 -> 正面视觉优化。
    *   向前移动动力学模拟 -> 肌肉体积优化。
    *   低分辨率 SDF 融合 -> 极简 Lowpoly 网格化。
    *   精简动画绑定（Idle/Hit/Move）。
3.  **输出**：适配 120 像素空间的、带精简动画的 Lowpoly 生物资产。
