# XPBET 产品架构知识图谱

基于 ECharts 的可交互式产品架构知识图谱，用于展示 XPBET 体育博彩平台的模块关系和开发优先级。

## 功能特性

### 可视化展示
- 所有模块以节点形式呈现，通过连线展示模块间的关联关系
- 节点大小和颜色按优先级区分（P0红色最大、P1橙色、P2蓝色）
- 支持力导向布局和环形布局切换

### 交互功能
- **拖拽移动**：可以自由拖拽任意节点调整位置
- **缩放平移**：鼠标滚轮缩放，拖拽画布平移
- **点击查看详情**：点击节点在右侧显示模块详细信息
- **关联跳转**：点击关联模块可快速跳转查看

### 筛选功能
- 支持按 P0/P1/P2 优先级筛选模块
- 快速聚焦不同优先级的模块

### 导出功能
- 支持导出为 PNG 图片

## 适用场景

| 场景 | 用途 |
|------|------|
| 架构会议 | 展示系统上下文图，讨论模块优先级和版本规划 |
| 规划会议 | 展示模块地图和关联关系，便于团队理解整体架构 |
| 新人培训 | 快速了解系统整体架构和模块职责 |

## 优先级说明

| 优先级 | 说明 | 目标时间 |
|--------|------|----------|
| P0 | 核心模块，必须优先开发 | 2026年3月上线 |
| P1 | 重要模块，第一版本必备 | 2026年6月上线 |
| P2 | 延后模块，世界杯后迭代 | 2026年下半年 |

## 技术栈

- ECharts 5.4.3
- 纯前端实现，无需后端服务
- 支持现代浏览器
