# 世界变迁引擎 · 调参实验台 (world_sim_lab)

独立前端，用于**验证**与**调参**仓库内的 JS 版世界变迁引擎（`src/world_sim`）。
通过 Vite 别名 `@engine` **实时引用**引擎源码——不复制、不打包快照，改引擎后刷新页面即生效。

## 运行

```bash
cd tools/world_sim_lab
npm install
npm run dev        # 启动后打开终端输出的本地地址
```

构建产物：`npm run build`（输出到 `dist/`），本地预览 `npm run preview`。

> 需要 Node 18+。引擎源码位于上两级的 `src/world_sim`，`vite.config.js` 已用
> `server.fs.allow` 放行根目录外的引擎读取，无需额外配置。

## 功能

- **全参数滑块**：引擎参数按「地幔 / 气候 / 地形 / 晶石 / 生物 / 人类 / 人类吸能基地」分组（lil-gui）。
  绝大多数参数**逐帧生效**——拖动滑块下一帧即可看到变化，无需重建。
- **地形调参**：地形层参数包含「地质变迁倍率」、抬升、侵蚀、坡度阻隔、盆地热滞留与「高地隔绝地幔热」，用于观察高原、盆地和山口如何改变迁徙与天气；晶石吸能不受地势高低影响。
- **晶石灾害实验流**：工具条支持生成 `source-basin` 双叶源井盆地与 `source-circle` 圆形源井地形、载入通过 50×50 / 600 步稳定窗口复验的可解参数、生成“环形前缘”（中心休眠、外圈活跃）预览、部署环形前缘半径 9 的六点吸能阵列、部署推荐人类吸能基地、命中推荐关键割集、清除基地。
- **算法叠加层**：画布可显示关键点/关键割集、源井封印目标、人类吸能基地半径、吸能影响区，与 `src/world_sim` 的 `analyzeCrystalDisaster()`、`human_energy`、`terrain_features` 能力保持同步。
- **播放控制**：运行 / 暂停（空格）、单步（S 键 / ⏭）、重置（⟲）、1–50× 速度。
- **六图层视图**：地幔 / 地形 / 气候 / 晶石 / 生物 / 合并。地形层会单独显示高低地势、盆地阴影与陡坡纹理。
  叠加层可开关：能量流、迁徙者、雷暴、风向、关键点、源井、吸能基地、吸能区、网格线、重生点标记。
- **实时指标曲线**：聚落 / 迁徙者 / 物种 / 晶石 / 均温 等多序列滚动折线（各序列独立归一化，
  图例点击可显隐）。侧栏另有「世界状态」读数卡片与逐格**检视**（悬停查看某格全部字段）。
- **预设导入导出 + 随机种子**：导出当前参数为 JSON、再导入复现；勾选「固定种子」后，
  同一组参数 + 同一 seed **每次跑出完全相同的世界**，包括丰富的初始地形高度细节。

| 操作 | 效果 |
|---|---|
| 滚轮 | 以光标为锚缩放 |
| 拖拽 | 平移 |
| 双击 | 复位视图 |
| 悬停 | 在右侧「格子检视」显示该格全部字段 |
| 勾选「点选设定重生点」后单击 | 设置 / 取消人类重生点 |

## 设计要点

- **只读引擎、绝不修改**：渲染与指标层只「拉取」`engine.grid` 的只读字段，与引擎
  「视图轮询、引擎从不推送」的规范一致。本项目不改动任何引擎源码。
- **`src/sim/engine-bridge.js` 是唯一 import 引擎的文件**，集中桥接点，隔离引擎演进影响。
- **地形层只读显示**：画布读取 `terrainElevation` / `terrainSlope` / `terrainBasinDepth` / `terrainMoveCost`，用于单独地形图层、悬停检视和状态统计，不反写模拟状态。
- **参数按引用传入引擎**（`new SimulationEngine(w, h, params)`），故滑块原地改字段即逐帧生效；
  仅**结构性参数**（供给点数量 / 转速，标 `*`）与网格尺寸 / 种子变化才会重建引擎。
- **可复现随机**：直接使用引擎原生种子源（`new SimulationEngine(w, h, params, { seed })`
  → `rng.js` 的 `createSeededRandom`）。引擎及各层全部走 `this.random()`，无全局
  `Math.random`，因此同一 seed 在本实验台与任何研究脚本中复现同一世界。
- **启动自检**：加载时用引擎真实 `DEFAULT_PARAMS` 校验参数面板键覆盖，
  引擎新增 / 删除参数会在控制台告警，提示同步 `params-schema.js`。
